# Commitment Desk

Promises disappear into notes. Later updates create conflicting dates, and generic assistants can turn untrusted text into instructions. Commitment Desk turns selected notes into cited commitments and next actions that people review before saving.

The local app previews the complete request, calls NVIDIA Nemotron through Nebius Token Factory, and stages the answer, memories and actions. Exact-source citations must validate. Explicit approval commits changes atomically; superseded records retain history. Corrections and deletion remove linked active records. No email, shell or calendar execution exists.

Built with Node.js HTTP, SQLite and plain JavaScript, using the exact model nvidia/NVIDIA-Nemotron-3-Nano-30B-A3B. A shared persistent budget ledger reserves input plus reasoning/output cost before each call. Failures halt evaluation; old plans cannot silently generate again.
